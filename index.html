Entre com e-mail e senha para guardar seus roteiros no Firebase e abrir tudo de outro computador ou celular.

Configure o Firebase no arquivo antes de usar o login.
  1. Crie um projeto no Firebase.
  2. Ative Authentication com e-mail e senha.
  3. Ative o Cloud Firestore.
  4. Cole sua configuração no bloco firebaseConfig deste arquivo.
  5. Publique no Firebase Hosting para acessar de qualquer lugar.
